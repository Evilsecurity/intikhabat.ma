## 📝 وصف المشروع (Description)
**"صوت المواطن"** هو تطبيق ويب (Single Page Application) صُمم ليكون جسراً رقمياً يتيح للمواطنين التعبير عن تطلعاتهم وتقييم الخدمات العامة (صحة، تعليم، بنية تحتية، إلخ). يتميز المشروع بواجهة مستخدم عصرية (Modern UI) وتجربة مستخدم (UX) سلسة تعتمد على نظام التبويبات والنتائج اللحظية.

## ✨ المميزات التقنية (Features)
* **نظام تصويت ذكي:** يمنع تكرار التصويت من نفس المتصفح لضمان مصداقية النتائج (Local Storage Logic).
* **تحليل بيانات فوري:** لوحة نتائج (Live Dashboard) تعرض النسب المئوية والإحصائيات فورياً برسوم بيانية تفاعلية.
* **إحصائيات ذكية:** حساب تلقائي لمتوسط التقييمات والأولويات القصوى.
* **تصميم متجاوب (Responsive):** متوافق تماماً مع الهواتف الذكية والأجهزة اللوحية والحواسيب.
* **خفيف وسريع:** كود نظيف مكتوب بـ Vanilla JS لضمان أعلى أداء.

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **HTML5:** للهيكل البنائي وتنسيق المحتوى العربي (RTL).
* **CSS3:** للتنسيق الجمالي، والأنيميشن (Fade-in)، والتدرجات اللونية.
* **JavaScript (Vanilla):** لمعالجة المنطق البرمجي، الحسابات الإحصائية، وإدارة البيانات.
